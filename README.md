# 小児科 受付ランチャー（KOKUBA T0124）

鈴鹿市の小児科2院の当日受付を、開始時刻ちょうどに開き、入力を最短で終わらせるための小さなWebアプリ。
iPhone と MacBook の両方で動く。GitHub Pages に置いてあるので、母艦PCの電源に関係なく開ける。

## 大事な前提

- **確定（「予約する」ボタン）は必ず人が押す。** 全自動では取らない。
  受診するかどうかは朝に子の様子を見て決まるため、無人で取ると無断キャンセルになる。
- **ネット受付には診察券番号が要る。初診は電話でしか取れない**（2院とも）。
  設定でその医院の診察券欄を空にしておくと、その子は発射台と自動入力から自動で外れる。
  2026-09-20 時点で、しばたでネット受付できるのは3人のうち1人だけ（残り2人は未受診）。
- **個人情報はこの端末の中だけ**（ブラウザの localStorage）に保存する。
  名前・診察券番号・誕生日・電話番号・キャンセルコードは GitHub にも、どのサーバーにも送らない。
- しばた（アイチケット広場）の利用規約に配慮し、**内部APIを叩く実装はしない**。
  やるのは「時刻ちょうどに受付ページを開く」「開いた画面の欄を埋める」だけ。

## 画面

| ファイル | 中身 |
|---|---|
| `index.html` | 入口（3つのボタン） |
| `shibata.html` | しばた小児科の発射台（午前8:30／午後14:30） |
| `shindo.html` | しんどう小児科の発射台（開始時刻は未確定・設定で直す） |
| `settings.html` | 基本設定・自動入力スクリプトの生成 |
| `rehearsal.html` | 練習用の入力画面（本物そっくりのにせもの。どこにも送信しない。人数1〜5を切り替えられる） |

`?dry=1` を付けると、時刻になっても実際には開かない（練習用）。`?test=20` で20秒後を発射時刻にできる。

## 仕組みのポイント

- **時計合わせ**：自分のページへHEADを1回投げ、応答の `Date` ヘッダと端末時計の差を測る。
  ヘッダは秒までしか持たないので平均0.5秒を足して補正する（誤差 ±0.5秒）。
  そのため発射は開始ちょうどではなく **1秒後ろ**（08:30:01）に置いてある。早撃ちで弾かれる方が損が大きい。
- **休診日**：しんどう＝水日祝／しばた＝木日祝。祝日表は `app.js` の `HOLIDAYS`（2026-2027年ぶん）。
- **発射**：iPhoneのSafariはタイマーからの `window.open` を塞ぐので、**同じタブで移動**する。
  しんどうは診察券番号＋誕生日をその場で組んだフォームでPOSTしてログイン済みの画面に着地する。
- **自動入力**（`app.js` の `fillerSource`）：欄を **見えているラベル** で探すので、画面の作りが多少変わっても効く。
  生年月日は選択肢の数字（年＝1900超／月＝12以下／日＝31以下）で見分ける。
  **送信ボタンは絶対に押さない。** 値が既に入っている欄は上書きしない。
  この見分け方のため、**入力画面と同じページに「1〜5」の選択メニューを置くと月の欄と誤認する**。
  練習用ページの人数切替をボタンで作ってあるのはそのため（本物では人数選択は1つ前の画面にある）。
- **公式アプリとの関係**：`park.paa.jp` には Universal Links の設定ファイルが無い（2026-09-20 に404を確認）。
  → **Webのリンクからアイチケットのアプリは開かない。** Webとアプリは別ルートで、行き来できない。

## まだ確かめていないこと

1. 自動入力を**本物の**しばた入力画面で走らせていない（受付時間内かつ空きがある時しか開かない）
2. しんどうの受付開始時刻（午前・午後）が公表されていない → 実測して設定で直す
3. しんどうの外部からのログインPOSTが通るか（通らなければ「着地先＝確実」でも同じなので、手でログインに落とす）
4. しんどうに何人ぶんの診察券があるか（しばたは1人と判明済み）
5. 複数人まとめて取るときキャンセルコードが1つか人ごとか（当面は1人なので影響なし）
