受診する子最大5人

通ったことがない医院の診察券欄は空のままにしてください。 2院ともネット受付は診察券番号が必須で、初診は電話でしか取れません。 空にしておけば、その子は発射台と自動入力から自動で外れます。 初診で一度受診すると番号がもらえるので、そのときここに入れてください。

みんなに共通の値

キャンセルコードとは：しばたの受付画面で毎回「4桁の数字を自分で決めて入れる」欄です。 取った受付をあとで取り消す／確認するときの暗証番号になります。医院が決めるものではないので、 ここに好きな4桁を1つ決めて入れておけば、毎回それを使い回せます（覚えておく必要もなくなります）。

受付開始の時刻秒まで

医院が受付を開ける時刻に「1秒」足した時刻を入れてあります。早撃ちして「時間外」で弾かれる方が損だからです。

しんどうのログイン3人まとめて取るなら必須

しんどうは1人ぶんの診察券番号でログインする仕組みです。ログインした子の画面に ほかの子を出すには、その子を代表者にした家族登録（最大5人）が要ります。

家族登録のやり方（1回だけ・いまできます）
しんどうの受付サイトにログイン → トップの「家族登録」 → 足したい子の診察券番号と誕生日を入れて「登録確認」→「登録する」。 これを済ませると、受付のときチェックを入れるだけで子を選べます。
※すでに別の家族登録の代表者になっている子は登録できません。その場合は一度解除してからやり直します。

しんどうの着地先

開始時刻になったとき、診察券番号と誕生日を送ってログイン済みの画面に着地します。

「一気に」は効けば2タップ減ります。効かなかったら「確実」に戻してください。

自動入力しばた用

しばたの入力画面で走らせると、上の値を一気に流し込みます。送信ボタンは押しません（確定は自分）。

iPhoneの用意（1回だけ）
ショートカットアプリ → ＋ → 「Webページでスクリプトを実行」を追加 → 上の「iPhone用をコピー」で取った中身を貼る → 名前を「予約うめる」にする → 設定で「共有シートに表示」をオンにする。
使うとき：受付の入力画面で 共有ボタン → 予約うめる。

Macの用意（1回だけ）
ブックマークを1つ作り、URL欄に「Mac用をコピー」で取った中身を貼る。使うときは入力画面でそのブックマークを押す。

練習用の入力画面で試す

本物の受付は8:30／14:30にしか開きません。練習用のページ（本物そっくりのにせもの）で、 ショートカットが効くかを先に確かめられます。

この自動入力は、まだ本物の入力画面では試せていません（受付時間内かつ空きがある時しか開かないため）。 次の受付時間に1回試して、入らない欄があれば直します。

公式アプリ・呼出通知との使い分け

しばたには公式アプリ（アイチケット広場）があり、名前と診察券番号が最初から入った状態で予約画面が開きます。 ただしこのページのリンクからアプリは開きません（Web側にアプリへ渡す仕掛けが入っていないことを確認済み）。 Webとアプリは別ルートなので、どちらか片方を使ってください。

Webで取る日：発射台を1〜2分前に開いておく。時刻ちょうどに受付ページが自動で開くので、 自動入力 → 次へ → 予約する。
アプリで取る日：発射台のカウントダウンを時計として見て、0になったらアプリを開く （アプリ自身にカウントダウンは無いため）。アプリで取れるのは、そのアプリに登録済みの子だけです。

しんどうに公式アプリはありません。そのかわり受付サイトの「メール設定」で 当日呼出メール（順番が近づくと届く）・前日確認メール・予約完了メールを入れられます。 呼出の通知がほしいならこれを登録してください。
